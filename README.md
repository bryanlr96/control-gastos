# 💰 Budget Tracker App

Una aplicación web desarrollada con **React**, **TypeScript** y **Tailwind CSS** que permite a los usuarios definir un presupuesto, registrar gastos y llevar un control visual del mismo.

## 🧠 Funcionalidades

- Definir un **presupuesto inicial**.
- Añadir **gastos** asociados al presupuesto, evitando superar el total definido.
- Visualización del estado del presupuesto mediante una **barra de progreso dinámica**.
- **Listado de gastos** con posibilidad de **filtrar por categoría**.
- Edición y eliminación de gastos mediante un gesto de **deslizamiento horizontal (swipe)**.
  
## 🛠️ Tecnologías utilizadas

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## Posibles mejoras futuras
